# Ingrédients
- beurre mou    :   80g
- sucre         :   50g
- lait          :   2 cas
- oeuf          :   2
- banane mûr    :   340g (3)
- farine        :   300g
- bicarbonate   :   3 cac

# Recette
- beurre mou + sucre
- + lait
- + oeuf 1 à 1
- + banane écrasé
- + farine + bicarbonate
- Four 160°C **à froid**, 45mn-1h

**Note**:
- banane à écraser grossièrement pour garder une texture fondante
- lait : inutile ? acidité pour bicarbonate ?
